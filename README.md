# 每日早报插件 (astrbot_plugin_daily_report)

> 对机器人说一声「早」，秒回问候 + 实时天气 + 今日头条热榜 + 加密货币行情 + 每日一言，三条自然语言消息连贯送达。零 key、零依赖、国内直连可用。

---

## ✨ 特性

- **零依赖**：仅使用 AstrBot 核心 API，无需安装任何第三方 Python 包
- **零 key**：所有数据源均为免费公开 API，无需注册、无需 token
- **全平台兼容**：微信 / Telegram / QQ / 飞书 / Discord 等所有 AstrBot 支持的平台
- **国内直连友好**：币价数据源选用国内可直连的官方域名，无需代理
- **三条分开发送**：问候秒回不卡顿，天气和新闻并行抓取，体感流畅
- **冷热对比智能提示**：自动对比昨天气温，给出增减衣/带伞建议
- **高度可配置**：城市、经纬度、加密货币开关、币种列表均可自定义

## 📦 安装

### 方法一：AstrBot 插件商店安装（推荐）

1. 打开 AstrBot 管理面板（WebUI）
2. 进入 **插件商店**
3. 搜索 `每日早报` 或 `astrbot_plugin_daily_report`
4. 点击安装，等待完成
5. 在 **插件管理** 中确认插件已启用

### 方法二：手动 Git 安装

```bash
cd ~/astrbot/AstrBot/data/plugins
git clone https://github.com/YangPengWei666/astrbot_plugin_daily_report.git
```

然后在 AstrBot 管理面板中重启插件（或热重载）。

### 方法三：手动下载安装

1. 点击本仓库右上角 **Code → Download ZIP**
2. 解压后将文件夹放入 `data/plugins/` 目录
3. 确保文件夹名为 `astrbot_plugin_daily_report`
4. 在 AstrBot 管理面板中重启插件

> **安装后无需重启整个 AstrBot**，在插件管理页面点击「重载」即可生效。

## ⚙️ 配置

在 AstrBot 管理面板 → **插件管理** → 找到「每日早报」→ 点击 **配置**：

| 配置项 | 说明 | 默认值 | 示例 |
|---|---|---|---|
| `city_name` | 天气播报中显示的城市名称 | `北京市` | `上海市`、`广州市`、`成都市` |
| `latitude` | 天气查询纬度（小数点后两位） | `39.90` | 上海 `31.23`、广州 `23.13` |
| `longitude` | 天气查询经度（小数点后两位） | `116.40` | 上海 `121.47`、广州 `113.26` |
| `enable_crypto` | 是否在早报中包含加密货币行情 | `true` | 设为 `false` 则只播报天气+新闻+一言 |
| `crypto_symbols` | 币种交易对列表，逗号分隔 | `BTCUSDT,ETHUSDT,DOGEUSDT` | 见下方说明 |

`crypto_symbols` 支持所有币安现货 USDT 交易对，格式为 `币种代码+USDT`，多个用英文逗号分隔：

## 🚀 使用

对机器人发送以下任一触发词即可：

```
早 / 早上好 / 早安 / 早报 / morning / Morning / 早呀 / 早啊
```

触发后机器人会依次发送三条消息，全程无需额外操作。

> **提示**：触发词匹配不区分大小写，且支持前后带空格或标点（如 `早！`、`早上好~`）。

## 📄 数据源说明

| 数据 | 来源 | 是否需要 key | 国内直连 | 备注 |
|---|---|---|---|---|
| 天气 | [open-meteo.com](https://open-meteo.com/) | 否 | ✅ | 全球开源天气 API，含昨日对比数据 |
| 新闻 | 今日头条官方热榜 | 否 | ✅ | 内容已过国内审核，备用源为澎湃 RSS |
| 加密货币 | 币安 Vision 数据域名（主）+ Gate.io（备） | 否 | ✅ | 主源国内可直连，故障自动切换备用 |
| 每日一言 | [hitokoto.cn](https://hitokoto.cn/) | 否 | ✅ | 诗词类型，每日一句古文 |

### 数据源容错机制

- **加密货币**：主源 `data-api.binance.vision`（币安官方数据域名，国内可直连）请求失败时，自动切换 `api.gateio.ws`（Gate.io 公开 API），两次均失败才提示"币价暂时不可用"
- **新闻**：今日头条热榜为空或请求失败时，自动切换澎湃新闻 RSS
- 所有外部请求均有超时保护（单源 8 秒），不会因某个源挂了导致整条早报卡死

## ⚠️ 注意事项

### 1. 微信平台特殊限制

- 微信个人号适配器对**长文本**可能有截断或发送失败的情况，早报第三条内容较长（约 300-400 字），如遇发送失败可尝试减少币种数量或关闭加密货币
- 微信对**包含"比特币""加密货币"等关键词**的消息可能触发风控，如遇第三条发送失败，可将 `enable_crypto` 设为 `false` 测试是否为关键词问题
- 微信消息有频率限制，短时间内反复触发早报可能被限流

### 2. 时区与时间

- 天气数据中的"昨天/今天/明天/后天"基于**服务器所在时区**计算。请确保 AstrBot 的 `timezone` 配置为 `Asia/Shanghai`（管理面板 → 系统设置）
- 每日一言和新闻为实时获取，不受时区影响

### 3. 并发与性能

- 天气、新闻、币价、一言为**并行抓取**，正常情况下第三条在 2-3 秒内返回
- 如服务器网络较慢（如海外服务器访问国内 API），可能需要 5-8 秒
- 插件不占用后台定时任务，仅在用户触发时执行，无持续资源消耗

### 4. 数据准确性

- 加密货币价格为**现货实时价格**，24 小时涨跌幅和本月走势基于币安/Gate.io 公开数据
- 天气数据来自 open-meteo，与国内天气 App 可能存在 1-2 度偏差，属正常现象
- 新闻为今日头条热榜实时数据，每次触发可能不同

### 5. 升级注意

- 升级插件后，如配置项有变化，请到插件配置页面检查并保存一次
- 升级不会覆盖你已有的自定义配置

## 🔧 常见问题 (FAQ)

**Q: 发送「早」后没有反应？**
A: ① 确认插件已启用（管理面板 → 插件管理）；② 确认触发词完全匹配（支持 `早/早上好/早安/早报/morning` 等）；③ 查看 AstrBot 日志是否有报错。

**Q: 天气显示的城市不对？**
A: 请到插件配置中修改 `city_name`、`latitude`、`longitude` 三项，保存后重载插件。注意 `city_name` 只影响显示文字，实际查询依赖经纬度。

**Q: 加密货币价格不显示或显示"币价暂时不可用"？**
A: ① 检查服务器网络是否能访问 `data-api.binance.vision` 和 `api.gateio.ws`；② 国内服务器通常直连正常，海外服务器可能需要配置代理；③ 可临时将 `enable_crypto` 设为 `false` 跳过币价。

**Q: 新闻条数可以调整吗？**
A: 当前固定为 6 条今日头条热榜。如需调整可修改 `main.py` 中的 `NEWS_COUNT` 常量。

**Q: 可以定时自动推送早报吗？**
A: 本插件为**被动触发**设计（说"早"才发），不包含定时推送功能。如需定时推送，可配合 AstrBot 的定时任务（cron）或第三方调度工具定时发送触发词。

**Q: 支持多个城市的天气吗？**
A: 当前版本单实例只支持一个城市。多城市需求可部署多个 AstrBot 实例或自行扩展代码。

**Q: 为什么分三条发送而不是一条？**
A: ① 问候秒回，避免用户等待时以为没反应；② 天气抓取极快（0.2 秒），新闻币价较慢（2-3 秒），分开发送体感更流畅；③ 部分平台对长消息有限制，拆分后更稳定。
